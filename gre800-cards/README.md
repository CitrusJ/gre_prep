# 词间 · GRE 800 / 急救 1400 / 八词配对

直接打开 `dist/index.html`，或从根目录 `GRE-start.html` 进入。无需安装依赖或运行启动脚本。

左侧「背诵词库」可切换：

- 原 GRE 800：800 个词条、815 个考法、8 个 List。
- 急救 1400（2026）：1400 个词条、1892 个考法、14 个 List，保留音标、助记、相关词及 List / Unit / PDF 页码。

1400 使用「考频词表」：按原书 GRE 考频从高到低排列，同频保持原书顺序。每行右侧只有一个按钮：点击「加入特殊待复习」加入，已加入时再点即可移出。每页可选 25／50／100 词或全部，支持搜索、List 和特殊待复习筛选。

表格完整呈现各考法的中英文释义，保留原书编号、音标、助记、相关词和来源页码；近义词补充自已有词汇资料，并标明对应释义及来源。800 仍支持词卡、自认复习、反向回忆、测试和间隔复习；其自认模式选择不认识仍会自动加入特殊待复习，支持回退改选。

「八词配对」使用新增的《学而思GRE高频六选二等价1000词（2026版）》：每轮八个英文词，其中六个词配成三组，另外两个为干扰项。点选两词组成一组，配齐三组即可核对，剩下两个不用选；也可用 1–8 键选词。提交前可拆开、清空或撤销；提交后查看三组答案及两个干扰项各自的原表释义与页码，完成后可重练错题。干扰项来自另外两个来源组，出题时排除与本轮配对词或彼此存在原表关联的组合。配对按原词表的同义／等价关系，不仅凭拼写相似判断；完整六选二题仍需结合句子语境。

原表共 500 组、1000 词条（881 个不同词形或短语）；497 组用于自动练习，3 组原书拼写或释义疑点保留在设置页的待核对说明中，可打开对应 PDF 页。出题会避开重复词、冠词变体及来源关系交叉的组合。

## 进度

学习记录自动保存到当前浏览器。800 与 1400 各自保存学习记录和特殊复习列表，切换词库不会覆盖另一套记录；在「学习分析」中导出、导入当前词库的 JSON 备份。八词配对有独立的「导出配对进度」「导入配对进度」。换浏览器、移动项目或清理浏览器数据前请先备份；这些记录与阅间综合训练独立。

旧六词配对的未提交轮次会补入两个干扰项，保留已有配对与撤销记录；已提交的六词历史继续按原题保留，重练时使用八词模式。

已有特殊列表、旧认识标记、原会话和测试成绩继续保留。当前表格只操作特殊待复习，旧认识标记不影响是否入选或筛选结果。JSON 备份保留这些记录；特殊列表按每个词的更新时间合并，移出列表也会保留时间记录。

## 资料与维护

原始词汇 PDF 和词表统一放在根目录 `materials/`，可打开 `../materials/index.html` 查阅。`dist/words.*` 为 800 词库，`dist/words1400.*` 为 1400 词库，`dist/equivalence-pairs.*` 为原表等价组；其他 `dist/` 文件是页面运行代码。

`dist/words1400-relations.*` 保存 1400 词表的补充近义词与来源证据，原词表的多种释义保持独立、完整。可运行 `scripts/build_1400_relations.py` 重建；同目录的 `words1400-relations-report.json` 记录来源校核与待核验原组。

`scripts/extract_vocab.py` 通过统一资料清单找到原始 PDF，重新提取需要 `pypdf`。`scripts/audit-lexicon.cjs` 用于词库关系校核。它们仅供维护数据，日常学习不需要执行。

新增词表的提取脚本为 `scripts/extract_1400.py` 和 `scripts/extract_equivalence.py`；相邻的 extraction-report JSON 记录数量、来源校验及提取核对结果。已生成的网页直接离线可用，无需安装这些开发工具。

核心校验：`node --test gre800-cards/tests/*.test.cjs`（在项目根目录运行）。
